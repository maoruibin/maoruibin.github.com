早晨刷到一篇文章，说 GPT-5.6 来了。

但最让我在意的，不是模型又强了多少，而是另一件事：ChatGPT 和 Codex 合并了。

我打开 Codex，点了一下升级。升级完之后，两个变化很明显。

第一个，应用图标变了。下面是 OpenAI 昨天出的一个 GIF，很形象地展示了这个合并过程。

![图 1：ChatGPT 和 Codex 合并效果](https://gudong.s3.bitiful.net/img/4498074d.gif)

之前是 Codex 的图标，现在变成了 ChatGPT。

第二个，打开页面后，里面提示：

> Codex is now the ChatGPT app。

![图 2：Codex 更新后的版本说明](https://gudong.s3.bitiful.net/img/c78ee508.png)

我当时第一反应是，这真是一个标志事件。

不是普通的产品改名，也不是换个图标这么简单。它更像是一个时代交接的信号。

### 1. 聊天框完成了它的启蒙任务

2022 年 ChatGPT 出来的时候，大家第一次真正感受到 AI。

那时候我们对 AI 的第一印象是什么？就是聊天。你问一句，它答一句。它能写文案、写邮件、讲知识、翻译、总结。

这种形态特别容易理解，因为它像一个更聪明的搜索框，也像一个随叫随到的老师。

所以后来不管是 ChatGPT，还是豆包、DeepSeek，大家默认打开 AI 产品，就是进一个聊天框。

这没问题。

聊天框完成了 AI 的大众启蒙。

它让普通人第一次知道，原来 AI 不是论文里的东西，也不是电影里的东西，而是每天都可以打开用的工具。

但今天再看，这个入口已经不够了。因为我们对 AI 的期待变了。

以前我们希望它会说。

现在我们希望它会干。

### 2. Codex 代表的是另一种入口

Codex 跟聊天框不一样。

聊天框里，你主要是在跟 AI 对话。Codex 里，你是在把一个任务交给它。

![图 3：Codex 主页面](https://gudong.s3.bitiful.net/img/873e0a5c.png)

它可以读文件，可以改代码，可以跑命令，可以看日志，可以做验证。

它不再只是回答“你应该怎么做”，而是开始真的去做。

这就是我觉得 ChatGPT 和 Codex 合并特别有标志性的原因。

更准确一点说，聊天并不是没了。它只是从舞台中央退到了一边。站到前面的，变成了 Work，变成了 Codex，变成了 Agent。

我早上看到的那篇[卡兹克的文章](https://mp.weixin.qq.com/s/EqgGQ2TkKhSv1eCKVLD-Vg)里，也提到了这个变化。

但我不太想把这篇写成发布会复述。因为对我来说，这件事真正戳中的，不是 OpenAI 又出了一个新模型，而是我回头一看，自己的工作方式已经提前变成这样了。

### 3. 我现在已经很少自己扣代码了

最近在公司做一个微博项目里的复杂需求。

做着做着，我突然发现，我的工作方式已经彻底变了。

不只是写代码，写汇报、写周报、做调研、做数据分析，几乎所有事情都在 Agent 化。

以前我会自己扣代码。

现在我更多是在给 AI 喂上下文。

比如写代码，我现在大概是这么做的。

第一步，把需求说清楚，让它先读文档，再读代码，不要急着动手。

第二步，把验证方式说清楚。这个需求怎么测，哪些日志要看，哪些数据要对，哪些边界要注意，都先讲明白。

第三步，让它写代码、加日志、自己先验证。如下就是我日常对话的一个场景。

![图 4：工作时让 Agent 读上下文](https://gudong.s3.bitiful.net/img/b68af469.png)

第四步，我运行起来，看日志，把问题继续喂回去。

它再改，我再跑，一轮一轮循环。

我不知道这是不是 Claude Code 里说的 Loop 编程模型。

但最近做需求时，我实际就是这么干的。

**我越来越觉得，人的核心工作不再是敲每一行代码，而是把正确的上下文放到 AI 面前。**

### 4. 写周报也是一样

我以前很少写周报，最近领导要求写。

周报这件事，本质上不难。

它就是把一周做了什么、有什么进展、接下来要做什么、核心重点是什么，整理成一封邮件。

但烦就烦在，信息是分散的。

邮件里有数据，代码系统里有需求和修复记录，数据分析平台里有指标，工作报告里有性能优化结论，还有一些重点工作进度，散落在不同地方。

以前手写周报，就是到处翻。翻完之后复制粘贴，再自己整理。

昨天我不想这么干了，就让 Agent 去读这些系统。

让它读邮件，找核心业务数据。

![图 5：让 Agent 去找邮箱里的性能数据报告](https://gudong.s3.bitiful.net/img/e3750ad8.png)

让它读代码系统，看最近进了哪些需求、修了哪些问题；让它读数据分析，看最近有哪些关键指标变化；让它读工作报告，理解性能优化进展。

最后让它把这些东西合成一封好看的 HTML 邮件。

连发邮件这一步，也是它帮我发的。

这件事让我感触挺深。

因为周报这种活，不是创造性很强的活。它真正费人的地方，是上下文分散。只要上下文拿齐了，后面总结、排版、发送，AI 都很适合做。

![图 6：最终发送周报](https://gudong.s3.bitiful.net/img/23cec7ff.png)

### 5. 以后最重要的是系统要对 Agent 友好

这也是我最近越来越确定的一件事。

未来不是某一个 AI 工具单独变强，而是所有系统都要对 Agent 友好。

什么意思？

就是系统不能只给人看，也要能让 Agent 读。

最好有 API，有 token，有 skill，能让 Agent 安全、可控地拿到信息。

如果一个系统开放了这些能力，Agent 就可以直接读上下文，然后干活。

如果没有开放，那就只能我自己复制粘贴。

这样 Agent 再聪明，也会被卡住。

我最近在公司就一直 push 这个事情。

公司内部有很多系统，其中有一个问题查询系统，可以看到业务相关的现网问题。

以前这个系统没有合适的 API，Agent 读不到。

我就去跟那边的同学反馈，说我们需要一个接口，让业务机器人可以查到相关问题。

对方很支持。上周反馈，这周 API 就给出来了。现在我在小业务群里做了一个机器人。

它可以快速读取最近业务相关的现网问题，再结合上下文生成排查结果。

![图 7：研发咚查询线上异常情况](https://gudong.s3.bitiful.net/img/9c42959b.png)

这个例子很小，但我觉得方向很对。

**系统把信息开放出来，Agent 才能真正干活。**

不然所谓智能体，最后还是卡在复制粘贴上。

### 6. 人的价值会往前挪

我现在越来越像一个编排者。

电脑上开着不同的会话窗口。这个 Agent 在写代码，那个 Agent 在整理数据，另一个 Agent 在生成周报。

我不断看它们的进度，补上下文，给反馈，做判断。

这不是说人没价值了。

恰恰相反，人的价值更集中。

因为业务背景 AI 不一定知道，需求背后的权衡 AI 不一定知道。哪些信息可信，哪些系统里有关键上下文，哪个结果算通过，哪个风险不能碰，这些都需要人来判断。

以前我们把很多时间花在执行上。以后很多执行会被 Agent 接走。人要做的是把问题定义清楚，把上下文找齐，把验证标准定好。

这个变化已经在我自己身上发生了。

写代码是这样，写周报是这样，做独立 App 也是这样。

这段时间我给自己的 Flutter 应用做了一套支付账号系统 SDK，以后其他应用都可以复用，不用每个 App 重复开发一遍。

这种设计性、高价值的活，我会交给更强的模型去做。

我自己负责说清楚背景、约束和验收方式。

### 7. 所以这次合并才有意义

回到 ChatGPT 和 Codex 合并这件事。

它当然是一个产品事件。

但我更愿意把它看成一个信号。

ChatGPT 代表的是 AI 的聊天时代。Codex 代表的是 AI 的干活时代。

现在这两个东西合到一起，意味着 OpenAI 也在把大众入口从“问答”推向“工作”。

Agent 时代其实早就来了。

只是不同人感受到的时间不一样。

程序员可能从 Claude Code、Codex 开始感受到，做办公的人可能从 WorkBuddy、ZCode 这类产品开始感受到。

普通用户可能要等到 ChatGPT 自己变成一个工作台，才会意识到：原来 AI 不只是聊天。

它可以替你处理文件，替你写代码，替你读系统，替你生成报告，替你发邮件。

它开始进入真实工作流。

这才是关键。

我还是那个建议。

如果你还没用过 Codex，可以先看我之前写的这篇：[没有 ChatGPT 账号，如何在国内用上 Codex？](https://mp.weixin.qq.com/s/RL39dTSGCudJFUnCsLXjrg)。

有条件的话，直接去用 Codex。

如果觉得 Codex 配置太折腾，或者暂时用不上原生 Codex，也可以看这篇：[Codex 太折腾了，终于等到一个下载就能用的国产版](https://mp.weixin.qq.com/s/bbdlCD_0X74tUzydB3gVkA)。

这篇讲的是 ZCode，我觉得它和 WorkBuddy 这类工具一样，更适合先上手。

重点不是站队哪个产品。

重点是你要开始习惯一种新的工作方式：把重复的执行交出去，把上下文喂清楚，把验证标准定明白，然后让 Agent 去干活。

我现在基本已经回不去了。
